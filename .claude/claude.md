IPC wiring, parsing `tasklist` CSV, anything that looks wrong but isn't.

**Electron security:** `nodeIntegration` stays off, `contextIsolation` stays on,
the renderer reaches Node only through `preload.js` + `contextBridge`. Flag any
shortcut around that.

## Debug hints: check these first

Common beginner causes. Point me toward the right one; don't just name the fix.

- **Two consoles:** `main.js` logs go to the terminal; renderer logs go to
  DevTools (Ctrl+Shift+I).
- **`exec` is async:** output arrives in a callback/promise. An empty list
  usually means I read it too early.
- **Stale main process:** edits to `main.js` need `npm start` again. Renderer
  edits only need Ctrl+R.
- **Main vs. renderer:** main has Node and no UI, renderer has UI and no Node,
  preload is the bridge.
